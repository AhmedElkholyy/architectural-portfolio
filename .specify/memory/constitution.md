# Architectural Portfolio Constitution

## Principles

1. **Editorial clarity first.** Every page must make the engineer's work, role, and next action immediately clear.
2. **Images carry the portfolio.** Project imagery must have meaningful alt text, be appropriately compressed, and never obscure project facts.
3. **Quiet, responsive interaction.** Motion is purposeful, respects reduced-motion preferences, and the site remains usable from 320px upward.
4. **Performance is part of design.** Avoid unnecessary libraries and optimize media before publishing.
5. **Honest project stories.** Do not invent project locations, scopes, dates, clients, or professional credentials; flag missing facts for the owner.

## Quality gates

- Run the production build before handoff.
- Verify keyboard navigation and sufficient text contrast.
- Verify mobile and desktop layouts.
- Add real project content only after it is approved by the portfolio owner.
