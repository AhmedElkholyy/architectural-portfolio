# Data Model: Bilingual Portfolio CMS

**Feature**: 001-portfolio-cms
**Date**: 2026-07-18

## Entity Relationship Overview

```
site_settings (singleton)
contact_page_settings (singleton)
projects ──< project_images
projects ──< project_featured (join for featured slots)
contact_messages
```

---

## Entity: `site_settings`

Singleton row (id = 1) storing global home/footer content and color tokens.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | int | PK, default 1, CHECK (id = 1) | Singleton guard |
| `profile_image_url` | text | nullable | URL to profile image in Supabase Storage |
| `about_en` | text | not null | About Me paragraph (English) |
| `about_ar` | text | not null | About Me paragraph (Arabic) |
| `footer_copy_en` | text | not null, default '' | Footer copyright text (English) |
| `footer_copy_ar` | text | not null, default '' | Footer copyright text (Arabic) |
| `footer_email` | text | not null, default '' | Footer email address |
| `footer_social_github` | text | nullable | GitHub URL |
| `footer_social_linkedin` | text | nullable | LinkedIn URL |
| `footer_social_instagram` | text | nullable | Instagram URL |
| `color_tokens` | jsonb | not null, default '{}' | Semantic color token values |
| `updated_at` | timestamptz | not null, default now() | Last modification timestamp |

**Validation rules**:
- `about_en` and `about_ar` must not be empty strings.
- `color_tokens` must be a JSON object with fixed keys: `background`, `surface`, `textPrimary`, `textMuted`, `accent`, `border`, `danger`.

**State transitions**: None (singleton row, admin-edited).

| Field | Type | Constraints | Description |

| `intro_ar` | text | not null, default '' | Intro text (Arabic) |
| `email` | text | not null, default '' | Contact email |
| `phone` | text | not null, default '' | Contact phone |
| `location_en` | text | not null, default '' | Location (English) |
| `location_ar` | text | not null, default '' | Location (Arabic) |
| `updated_at` | timestamptz | not null, default now() | Last modification timestamp |

## Entity: `projects`

Portfolio project with bilingual content and publication status.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | bigint | PK, generated by default as identity | Unique identifier |
| `title_en` | text | not null | Project title (English) |
| `title_ar` | text | not null | Project title (Arabic) |
| `description_en` | text | not null, default '' | Project description (English) |
| `description_ar` | text | not null, default '' | Project description (Arabic) |
| `category` | text | not null | Category label (free-text) |
| `location` | text | nullable | Project location |
| `year` | int | nullable, CHECK (year between 1900 and 2100) | Completion year |
| `cover_image_url` | text | nullable | Cover image URL in Supabase Storage |
| `featured_position` | int | nullable, UNIQUE, CHECK (featured_position between 1 and 3) | Featured slot (1–3) or null |
| `published` | boolean | not null, default false | Publication status |
| `created_at` | timestamptz | not null, default now() | Creation timestamp |
| `updated_at` | timestamptz | not null, default now() | Last modification timestamp |

**Validation rules**:
- `title_en` and `title_ar` must not be empty.
- `featured_position` must be 1, 2, or 3, or null. Unique constraint ensures at most one project per slot.
- `cover_image_url` is required to publish (`published = true` requires non-null cover).
- `category` is free-text entered by admin.

**State transitions**:
- `draft` → `published`: Admin clicks publish; cover image required.
- `published` → `draft`: Admin unpublishes; featured slot cleared if occupied.
- `draft`/`published` → deleted: Admin deletes; featured slot cleared.

## Entity: `project_images`

Gallery images associated with a project.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | bigint | PK, generated by default as identity | Unique identifier |
| `project_id` | bigint | FK → projects.id ON DELETE CASCADE | Parent project |
| `image_url` | text | not null | Image URL in Supabase Storage |
| `alt_en` | text | not null, default '' | Alt text (English) |
| `alt_ar` | text | not null, default '' | Alt text (Arabic) |
| `display_order` | int | not null, default 0 | Sort order within project |
| `created_at` | timestamptz | not null, default now() | Upload timestamp |

**Validation rules**:
- `alt_en` and `alt_ar` must not be empty (Constitution Principle II: meaningful alt text).
- `display_order` determines gallery sequence; admin can reorder.

**State transitions**: Images are added, reordered, or deleted with their parent project.

## Entity: `contact_messages`

Submitted contact form inquiries.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | bigint | PK, generated by default as identity | Unique identifier |
| `sender_name` | text | not null, CHECK (char_length between 2 and 120) | Sender name |
| `sender_email` | text | not null, CHECK (char_length <= 254) | Sender email |
| `message` | text | not null, CHECK (char_length between 10 and 3000) | Message body |
| `is_read` | boolean | not null, default false | Read status |
| `created_at` | timestamptz | not null, default now() | Submission timestamp |

**Validation rules**:
- `sender_name`: 2–120 characters.
- `sender_email`: max 254 characters, valid email format.
- `message`: 10–3000 characters.

**State transitions**:
- Created: Visitor submits contact form.
- `is_read`: false → true: Admin marks as read.
- `is_read`: true → false: Admin marks as unread.
- Deleted: Admin deletes message.

## Entity: `admin_users`

Managed by Supabase Auth; no custom table needed. The single admin user is created via Supabase Auth dashboard or migration. RLS policies reference `auth.uid()` to check admin identity.

**Admin identification**: RLS policies check if the authenticated user's ID matches the stored admin user ID (configured via a constant or a single-row `admin_config` table if needed).

## RLS Policies Summary

| Table | Operation | Policy |
|-------|-----------|--------|
| `projects` | SELECT | Public can read where `published = true` |
| `projects` | ALL | Admin only (auth.uid() = admin_id) |
| `project_images` | SELECT | Public can read images for published projects |
| `project_images` | ALL | Admin only |
| `site_settings` | SELECT | Public read |
| `site_settings` | UPDATE | Admin only |
| `contact_page_settings` | SELECT | Public read |
| `contact_page_settings` | UPDATE | Admin only |
| `contact_messages` | SELECT | Admin only |
| `contact_messages` | INSERT | Public (with rate limiting check) |
| `contact_messages` | DELETE | Admin only |
| `contact_messages` | UPDATE | Admin only (for is_read toggle) |

## Storage Buckets

| Bucket | Access | Purpose |
|--------|--------|---------|
| `profile` | Public read, admin write | About Me profile image |
| `projects` | Public read, admin write | Project cover and gallery images |

**Upload validation**: Images must be JPEG, PNG, WebP, or AVIF. Max 5 MB for profile/cover, 10 MB per gallery image. Client-side compression before upload.
